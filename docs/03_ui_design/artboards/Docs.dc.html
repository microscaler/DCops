Quick Start
Declare an IP pool and a boot profile in Git, apply the manifests, and watch DCops reconcile them into NetBox and the PXE service. This walkthrough takes about ten minutes on the shared development cluster.
1. Create a tenant
apiVersion: dcops.microscaler.io/v1alpha1
kind: NetBoxTenant
metadata:
  name: datacenter-tenant
spec:
  name: Datacenter Tenant
  tokenSecretRef:
    name: netbox-token-platform
The controller resolves the NetBox API token from the referenced Secret and creates the tenant. Its status shows the NetBox ID once reconciled.
