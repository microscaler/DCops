# Testing

DCops follows Test-Driven Development (TDD) principles.

## Test Coverage

- Minimum 65% coverage required
- Target 80% coverage
- All code must be tested

## Running Tests

```bash
cargo test
cargo nextest run
```

## Test Types

- **Unit Tests** - Test individual functions
- **Integration Tests** - Test controller behavior
- **E2E Tests** - Test full workflows

## Best Practices

- Write tests before code
- Ensure all tests pass
- Maintain high coverage
