# Development Setup

Get started developing DCops.

## Prerequisites

- Rust toolchain (see `rust-toolchain.toml`)
- Docker Desktop
- kubectl, kind, and Tilt
- Python 3

## Dev Container

The easiest way to get started is using the Dev Container:

1. Open the project in VS Code or JetBrains IDE
2. Reopen in Container
3. All dependencies are pre-installed

## Local Setup

1. Install Rust toolchain
2. Install Docker
3. Install Kubernetes tools
4. Run `just setup` (if using Just)
