# Installation

DCops requires a Kubernetes cluster and a NetBox instance.

## Prerequisites

- Kubernetes cluster (1.24+)
- NetBox instance (4.0+)
- kubectl configured to access your cluster

## Installation Steps

1. Install the CRDs
2. Deploy the controllers
3. Configure NetBox connection
4. Create your first IP pool
