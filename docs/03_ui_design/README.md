# DCops UI — screen designs

> **Status:** Draft mockups for review · **Canvas:** https://claude.ai/code/artifact/bb328bdf-45ee-4d3a-8310-0133d6524ee8
> **Source:** `artboards/*.dc.html` + `artboards/canvas.json` (generated by `generate_artboards.py`; edit the generator, not the HTML)

The three UI folders (`ui/`, `ui-dashboard/`, `ui-docs/`) were consolidated into `ui/` — see `ui/README.md`. These mockups define the single application's screens. Visual tokens are lifted from `ui/src` (background `#faf9f7`, sage `#4a5a4c` / `#2d4a2f`, border `#e5e3df`, greys `#2d3748` / `#4a5568` / `#6b7280`, tint `#f1f0ed`, green tint `#e8f0e9`), so the designs are an evolution of the existing app, not a restyle. The one structural change: a left sidebar replaces the top *Docs / Contributor / Admin* tabs so operational sections and documentation share one navigation.

Every other NetBox kind (IP addresses, VLANs, VRFs, sites, locations, manufacturers, …) uses screens 4 and 5 with its own columns; no separate mockup is needed.

## Regenerating

```bash
python3 docs/03_ui_design/generate_artboards.py   # writes artboards/*.dc.html + canvas.json
```

Then re-seed and republish the canvas (design skill) or open the `.dc.html` files directly in a browser to review.
